TaskFlow ✓

TaskFlow is a responsive student task tracker designed to help users organize assignments, projects, and deadlines efficiently.

Built using **HTML, Tailwind CSS, and Vanilla JavaScript**.



 Features

* Add new tasks
* Set task deadlines
* Delete tasks
* Task counter
* Responsive design
* Mobile navigation menu
* Local storage support



Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* Local Storage API


How It Works

1. Enter a task name
2. Select a due date
3. Click **Add Task**
4. View saved tasks
5. Delete completed tasks

Tasks are automatically saved in the browser.
